# xauusd_ml_scratch — 从零构建的 1m 管线（三段式方法论）

完全不复用旧管线（xauusd_ml_v2）的代码；仅继承原始数据与失败教训。

## 方法论（用户指令，最高优先级）
1. **阶段1** ML清洗 + 特征工程 → 找出哪些数据有用、哪些波段扣成本后能吃到
2. **阶段2** ML因子挖掘
3. **阶段3** 模型训练（只能放最后）

## 口径
- 数据：原始 M1（`upload/5_extracted/XAUUSDc_M1_*.csv`），切 2023-01 起，重建 43 个月度文件于 `download/xauusd_data/`（列 time,open,high,low,close,volume）
- 成本：单边点差 $0.03，commission 0（往返 $0.06）；2023 点差列全零，故用假设成本
- 切分：核心训练=2023（拟合=2023-01~09 + 早停=2023Q4），**内部验证段=2024H1（唯一消融试验田）**，OOS=2024-07 后**本轮绝不触碰**
- 信号语义：bar t 收盘决策，t+1 开盘入场，冻结几何 TP=3.0×ATR60 / SL=1.5×ATR60 / 超时 H=360min，一次一仓，出场后冷却 1 根

## 阶段结果（全部真实数字）
- **P1a ML清洗**：IsolationForest（仅 2023 拟合）→ 2023 清洁率 99.0%，2024H1 97.4%；异常集中 12–14 点（美盘数据窗）与周日开盘
- **P1b 波段画像**：24 点几何网格（随机口径全为 −5~−7c/笔，无免费午餐）→ 选型改为最小化模型命中率缺口 → **kE=3.0 / PLR=2.0 / H=360**（TP中位$1.20/SL$0.60，平均解析 11.3 分钟，缺口 3.4pp）。宇宙=hour×ATR三分位单元格中位 MFE_net(60min)≥$0.60，保留 48/72 格（92% 覆盖）。可吃性画像 AUC 0.741（ret240/atr_ratio/时段主导）
- **P1c 特征**：66 因子，截断一致性因果校验 0 违规
- **P2 因子挖掘**：单因子 LGBM AUC + 规格化 RankIC（剔除障碍尺寸机械通道）→ 每方向冻结 18 个；单因子 AUC ≤0.511（多空近镜像：yL+yS 基率=0.999，方向一维）
- **P3 单模型**：时间衰减权重（τ=120d），早停 2023Q4 → **val(2024H1) AUC：long 0.5043 / short 0.5006**（1-2月 0.52+，3-6月衰减）

## ② Regime门控 × δ收紧消融（2024H1，`results/ablation_regime_delta.csv/json`）
δ = 中部不交易带宽度（z=pL−pS 方向分数，阈值 2023 拟合段冻结；δ=0.5 全交易 → δ=0.02 只交易两端 2%）。每配置配随机方向孪生 → 差=纯方向alpha。

| 关键单元格 | n | avg $/笔 | 方向alpha | t |
|---|---|---|---|---|
| δ=0.50（全交易, all） | 10,576 | −0.046 | +0.010 | −2.87 |
| **wings(low+high) × δ=0.02** | **470** | **+0.061** | **−0.045** | 0.51 |
| high × δ=0.02（262空） | 306 | +0.080 | +0.363 | 0.43 |
| low × δ=0.12（614多） | 826 | +0.014 | +0.071 | 0.70 |
| mid × δ=0.02 | 46 | −0.262 | −0.270 | −2.40 |

结论：**减脂有效**（10,576→470 笔，avg −4.6c→+6.1c；mid 段全线显著为毒）；**增肌有限**（尾部 alpha 真实存在：high 空尾 +9.8c/笔、low 多 +3.2c/笔，但 t<1，96 格扫描存在选择噪声，δ=0.01 反转）。最佳点 be_cost=$0.12（可承受 2× 成本假设）。频率仅 2.6 笔/天。

## ① 信号相关性纯诊断（`results/diag_corr_matrix.png` / `diag_corr.json`）
- 14 对 |ρ|>0.7：vol-state 五因子（atr_ratio/atr_z/rv_ratio_60_1440/rv_1440/atr_lvl）实为一个因子
- z_dir 由 vol-state（|ρ|≈0.26）+ day_vs_open + session 驱动；微动量族 |ρ|<0.1 几乎不参与
- **单模型本质=波动状态计时器**：高波动→偏空（spike fade），低波动→偏多（calm drift）
