# XAUUSD ML v2 — 防泄露量化训练管线

升级自原始 `ml_trading` / `retrain_weekly.py` 代码。核心变化：**修掉 4 处数据泄露、
ATR 自适应止盈止损、purged 月度滚动走查（按你指定的 24-36 个月训练 + 验证月滚动并入）、
真实成本回测模拟器**。本目录所有结果均为真实运行输出（2026-09-05 首版，2026-09-08 增v3盈亏比重写、v4平衡几何），
无任何模拟或估算数字。

## 一、原代码的问题与本版修复

| # | 原代码问题 | 危害 | 本版修复 |
|---|-----------|------|---------|
| 1 | 三重障碍标签前瞻2小时，但训练折右端未清理 | 训练标签直接读到测试期未来数据 | 每折训练窗右端 purge（horizon + 6根M5 embargo，共30根） |
| 2 | Optuna 目标函数直接用走查测试集表现调参/阈值 | 对测试集过拟合（最严重） | 调参+阈值只在训练窗内部（前80%拟合，尾20%校准，带purge gap），冻结后才预测OOS |
| 3 | holdout 被最多5000次trial反复窥视直到通过 | holdout 独立性被烧毁 | 全程无 holdout 窥视；24个OOS月一次性汇总，含Bootstrap置信区间 |
| 4 | 固定 TP=$3.5/SL=$2.0 | 金价1830→5200、波动率放大~4倍，固定障碍2026年超时率从23.6%塌缩到0%（退化） | ATR自适应障碍：TP=2.0×ATR(24h)、SL=1.143×ATR(24h)，盈亏比保持1.75 |
| 5 | 超时交易按全额止损亏损计 | PnL低估 | 超时按真实2小时末平仓价结算 |
| 6 | 每根K线独立开仓（重叠持仓） | 虚增频率与PnL | 单持仓状态机 + 平仓后冷却10根M1 + 信号在下一根M1开盘入场 |
| 7 | 2022-23点差为0按0成本 | PnL高估 | 月度中位数填补（$0.20-0.28/笔），逐笔扣减 |

### 首版（legacy基线）真实结论（不粉饰）
1. **模型选择能力真实存在**：胜率39.3% vs 无条件基础率33.3%（+6pp），PnL比同频率随机基准好 $2,200。
2. **ATR障碍是胜负手**：同样特征，固定障碍亏钱（-$202），ATR障碍赚钱（+$1,282）。
3. **利润全部来自空头**（+$1,290 vs 多头-$8）：2024-2026大涨中2h尺度的急跌回调是主要盈利来源。
4. **利润集中风险**：2026-02/03 两个月贡献 $1,086（85%），其余22个月合计仅 +$196。盈利月 15/24。
5. **特征贵精不贵多**：弱信号场景下更多特征=更多过拟合维度。升级的价值在方法论，不在特征数量。
6. **点值敏感性**：若你的经纪商 point=0.01（非0.001），所有组合转为大额亏损（最优-$4,949）。**务必核对XAUUSDc的点值。**
7. 13/24 折出现阈值回退（内部验证段找不到盈利阈值→退到q=0.975极高选择性），这是系统诚实的自我保护。

## 三B、v3 盈亏比重写（2026-09-08，真实结果）

应"重写特征工程、尽量拉高盈亏比"的要求，新增两件事：

**1. 特征工程v3（features_v3.py，34个，全部因果、截断vs全量逐单元校验一致）**：
波动率挤压-爆发（atr_ratio/squeeze/range_ratio）→ ATR归一化多周期动量 →
Kaufman效率比+回归斜率（趋势质量）→ 突破深度/连涨连跌（结构）→ 量能/K线确认 → 时段/点差。
设计逻辑：宽TP几何下只该在"高质量趋势延续"上出手。

**2. 盈亏比导向几何（首训练窗2022-01~2024-07网格45点标定，无未来信息）**：
三重障碍下已实现盈亏比上限≈几何比。主几何 TP=4.0×ATR / SL=1.0×ATR / 6h（随机口径PLR 3.16）；

### v3盈亏比重写的真实结论（不粉饰）
1. **盈亏比 1.71 → 5.09（×3.0）**：v3aggr（v3特征+激进几何+PLR阈值目标）为盈亏比最高变体，avgWin$16.68 vs avgLoss$3.28，仍是正期望（+$610，PF 1.151）。
2. **代价是胜率与总额**：胜率39.3%→18.4%，总PnL $1,282→$610，Sharpe 1.13→0.85。盈亏比与胜率的权衡是几何决定的硬约束，不是免费午餐。
3. **归因诚实交代**：盈亏比提升的大头来自几何（旧特征+新几何也有PLR 3.98/4.82）；同几何下v3的34新特征**没有**在PnL上胜过旧23特征（$238 vs $830），再次验证"特征贵精不贵多"；但激进几何下v3拿到全场最高PLR（5.09 vs 4.82）且PnL差距缩小。

6. **利润集中**：v3aggr前2月占90%（最佳2025-10 +$296）；空头侧贡献+$668/总+$610，多头侧-$57。

## 三C、v4 平衡几何：胜率拉回32%（2026-09-08，真实结果）

应"18.4%胜率有点低"的反馈，新增**胜率下限约束下的盈亏比最大化**：

**1. 平衡几何（scripts/calibrate_barriers_v4.py，同一首训练窗2022-01~2024-07网格45点，无未来信息）：**
约束随机入场TP率（=胜率地基，v3aggr的随机TP率仅16.7/16.0%）多头>=28%、空头>=26%，
在此之内最大化盈亏比 -> 选定 **TP=3.0×ATR / SL=1.1429×ATR / 6h**（训练窗随机口径：PLR 2.165，TP率 28.0/26.6%，超时1.0%）。

**2. plr_wr阈值目标（backtest.py两段式）：** 内部验证段上先筛出实测胜率>=30%的阈值候选，
在其中最大化盈亏比；无一达标时退回美元期望目标（自然向高胜率端平衡）。OOS月份仍全程不参与。

### 平衡重写的真实结论（不粉饰）
1. **胜率 18.4% -> 32.2%（+13.8pp）**：阈值胜率下限0.30在24折中全部生效；逐折胜率中位33.6%（22.0~42.6%）；最长连亏从24笔降到14笔（比原基线的20笔还少）。
2. **代价是盈亏比 5.09 -> 2.40**（仍比原基线1.71高40%）；总PnL几乎不变（$610 -> $596）。
3. **风险调整后全面占优**：v3bal的Sharpe 1.33为全部11个变体最高（原基线1.13）；maxDD $250最低；盈利月18/24最多（原基线15/24）；前2月利润集中度49%（原基线85%、v3aggr 90%）；且是唯一多空双绿变体（多+$289/空+$307）。

5. **操作点前沿（几何决定，可自由选）**：胜率39.3%/PLR1.71（旧几何）→ 32.2%/2.40（平衡，推荐）→ 22.2%/3.98 → 18.4%/5.09（激进）。盈亏比与胜率的交换是三重障碍几何的硬约束，同几何内模型只能平移几个点。
6. **统计诚实**：v3bal Bootstrap CI [-0.095, +1.004]$/笔 仍含零（仅原基线[+0.04,+0.71]不含零）；阈值回退 5/24折（原基线13/24，更稳）。连亏、盈亏比、Sharpe均为1,331笔真实交易的直接观测。

## 五、如何在你自己的机器上跑

```bash
# 依赖: pandas numpy lightgbm xgboost numba scikit-learn matplotlib
# 1) 改 config.py 的 data_path 指向你的CSV, 然后全流程:
python run_all.py --stage all --features v2,legacy

# 2) 只跑最优组合 (推荐, CPU友好):
python run_all.py --stage prep --features legacy
python run_all.py --stage tune --features legacy
python run_all.py --stage wf   --features legacy

# 3) 盈亏比导向变体 (v3特征+激进几何):
python run_all.py --stage prep --features v3,v3aggr
python run_all.py --stage tune --features v3 --direction long
python run_all.py --stage tune --features v3 --direction short
python run_all.py --stage wf   --features v3aggr

# 3b) 平衡变体 (胜率32%/盈亏比2.4, 风险调整最优; 超参复用v3已冻结参数):
python run_all.py --stage prep --features v3bal,legacy_bal
python run_all.py --stage wf   --features v3bal,legacy_bal

# 4) 分析出报告/图表:
python analyze.py

# 5) 每周/每月重训生产模型 (默认v3bal平衡推荐; 也可 --variant v3aggr 纯盈亏比 或 legacy 原基线):
python train_final.py --variant v3bal --data_path 你的新CSV

# 6) 实盘: EA每5分钟调 predict_signal(recent_m1_df) 拿信号+动态TP/SL距离
```
- M1→M5 重采样是内置的"切一小块"：数据量÷5，2核CPU即可跑完24折走查（本机实测全程约35分钟）。
- GPU机器想跑M1原精度：`config.py` 里 `resample_rule="1min"`，horizon 语义不变（仍2小时）。
- 中断恢复：每折checkpoint，重跑自动跳过已完成折。

## 六、EA对接要点（与原版不同！）

1. `predict_live.predict_signal()` 返回 **动态 tp_dist/sl_dist**（ATR自适应），EA不能再用固定3.5/2.0挂单。
2. 多空阈值独立（trading_config.json），双向同时触发取超额更大一侧（与原EA逻辑一致）。
3. 单持仓 + 平仓后冷却10根M1；止盈止损由EA执行，垂直障碍v3族为6小时未触发按市价平仓。
4. v3特征需要 TICKVOL 列与约 16000 根最近M1（10个交易日回看）；特征缺失一律返回 HOLD。
5. 当前生产模型 = v3bal（平衡几何）：TP=3×ATR、SL=1.143×ATR、6h平仓，阈值0.3925/0.2934（2026-09-08重训）；要切回纯盈亏比用 `train_final.py --variant v3aggr`。
