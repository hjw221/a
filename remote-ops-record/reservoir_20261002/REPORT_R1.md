## 1. 架构落地（对用户规格的忠实映射 + 两处工程修正）

| 层 | 用户规格 | 实现 | 修正/披露 |
|---|---|---|---|
| L1 储层 | 500–1000 稀疏神经元，ρ<1 | 500（探针 1000），密度 10%，ρ=0.95，tanh，W 锁死 | 谱半径用一次性 eig 缩放 |
| L2 状态自组织 | Streaming GMM/DPGMM 惊异度自生长 | 对角 GMM，Mahalanobis²>36 + 冷却 96bar 触发生长，权重指数衰减，弱组件剪枝 | 修了剪枝时 mu/sd/w 长度失同步 bug |
| L3 突触演化 | 遗忘 RLS 每根 Bar 递推 | λ 默认 **0.999**（非 0.995），δ=1e-6 正则 + trace 上限 + 周期对称化 | **关键修正**：D=505 维下 λ=0.995 有效记忆 200bar<维度 → 协方差缠绕，三重防护 |
| 目标 | 未来 4 bar 联合能量分布 | y_var_rel（相对实现方差，0–6 截断）+ y_skew（Σr/√(Σr²+floor)，±2.5） | 标签延迟 4bar 进 RLS，全程无回望 |
| 仓位 | 非对称信息熵释放 | clip(2·ŝkew)×1/(1+0.5·v̂ar)×混沌门(0.6)，EMA 平滑 + 死区 0.05 + 速率 0.20/bar | 无固定止盈止损 ✓；v18 启示（波动率倒数仓位）以预测能量形式内置 |

## 4. 诚实结论

1. **学习为真**：能量头 IC 0.343、方向头 IC 0.020（洗牌归零验证）——三层闭环确实在流式学习。
2. **alpha 在波动率不在方向**：与 M1 时代 AUC 0.505 互证。1h 方向可预测性≈2%，24h 归零。
3. **瓶颈在执行层不在学习层**：所有视界毛利全正（+$411~+$1,080），但连续调仓换手 11,092 单位 × 悲观成本 = 毛利的 33 倍。低换手变体证明修复路径：成本砍 58%、毛利仅 −9%。
4. **算力承诺兑现**：单核 0.48ms/bar、引擎 4.1MB——无反向传播架构的 CPU 轻量主张属实。
5. **W_out 终身进化**：非收敛不动点，随 2024 牛市↔2026 高波切换持续漂移。
