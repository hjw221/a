# V16 引擎缺陷披露与真实地图（2026-10-02）

## 摘要

在执行用户三路线实验（A: Regime Gate / B: 解剖随机优于模型 / C: Donchian+Keltner 规则擂台）过程中，
发现并修复了 **两个项目级回测引擎 bug**。修复后重跑全部实验，历史成绩全部作废，真实地图如下。

## Bug 1：时域错位 3.47 天（污染全部历史 ML 成绩）

- **机制**：服务器 pandas 3.0.6 的 `DatetimeIndex` dtype 为 `datetime64[us]`；
  `astype("int64") // 10**9` 把**微秒**当**纳秒**除 → 时间轴落在千秒域；
  `+300` 秒的信号偏移实为 **+300,000 秒 ≈ 3.47 天**。
- **后果**：服务器上 v10–v16 全部实验的**进场时刻 = 信号后 3.47 天**。
  模型训练标签同样是"3.47 天后"的障碍 → 系统自洽但与意图完全脱节。
- **解释的历史谜团**：方向模型学不动（p_dir 恒 0.6）、v11 因子方向无 OOS alpha、
  v12 趋势共识全灭、ML 时刻表只有硬币级贡献——模型一直在预测 3.47 天后的市场，
  信号时刻的因子与目标几乎无关。
- **波及成绩**：$818（Task 20）、$962.5（v10）、$1,635.7（v13）、$1,391.8（v14）、
  $20,602.7（v15）——全部为错位域幻影。champ 配置在正确时域 + 正确结算下 base 臂 = **-$173**。
- **修复**：`astype("datetime64[s]").astype("int64")`（单位无关转换），stage_c_loop 3 处 + v16 系列 6 处。
  修复后服务器与本地（pandas 2.2.3 纳秒域）逐位一致。

## Bug 2：吊灯回望结算（污染全部吊灯出场成绩）

- **机制**：v15_exit.simulate_exit 的 CHANDELIER 模式中，`hit_sl` 置位后**循环不 break**，
  `hi_since`/`trail` 继续更新至 horizon 末，结算 `pnl = -trail_final`。
- **后果**：止损触发后交易**并未出场**，还按"回魂后"的吊灯位结算——
  多头触发后价格反弹 → trail 回升 → 亏损变小甚至转盈。
  这就是 v15"月月全正 / PLR 99 / $20.6K→$72K→$124K→$645K"的全部来源。
- **波及成绩**：v15 出场消融 11 臂、v16 breakout/diag/diag2/gate/geom 的全部吊灯系数字。
- **未波及**：STATIC/FIXED 出场（tp/sl 为固定值，结算正确）、TIME 出场（纯持有）。
- **修复**：v16_slip3.sim_true——触发即出场、pnl 用触发时刻通道价、blocked_until 用触发时刻解锁；
  另提供同根先高后低（乐观）与先跌后涨（保守）双口径。

## 修正版三路线结论

### 路线 B（解剖"随机优于模型"）
该问题本身随 bug 修复而消失——正确结算下随机时刻表没有任何正期望组合
（fixed 例外见下）。同 fixed 出场下笔均排序 **kelt 0.095 > model 0.047 > random 0.039**：
ML 选时相对随机有真实但微弱的质量优势（+21%），Keltner 突破再翻倍。
追高检验：model 追高率 9.5% vs random 20.4%（ML 避高成立，但不足以变现）。

### 路线 C（规则突破擂台）——唯一幸存的真实 edge
**Keltner(EMA20±2ATR14) 突破 + fixed TP2.5×ATR/SL0.4×ATR/90min = +$2,599**（4.5 年）：
- 五年 4 正 1 微负（2024 -$110），27,265 笔，月度 14 负
- 2026 占 59%（利润主导仍是 2026 大波动）
- 0.1×ATR stop 滑点下 edge 蒸发至 +$236 → **可部署性取决于成交质量**（限价/被动成交通道）
- Donchian20/55 与 hours_filter 变体在正确结算下未进入正区（未展示）

### 路线 A（Regime Gate）
失去放大对象——吊灯大利润是幻影，真实 edge（$0.095/笔）太薄，
RV/ER 标签的 OOS AUC（0.578 / 0.505）不足以在此薄 edge 上做有效门控。
挤压/ATR 规则 gate 在幻影口径下提笔均的结论不再适用。

## 关于历史基准 $732.7

该基准（m1sc_ad）来自更早的外部管线，其引擎是否存在同类问题无法从本仓库取证
（其 M1 时间转换写法与 bug1 同款：`astype("int64")//10**9//60`，且运行环境的 pandas 版本未知）。
在正确结算口径下，我们的最好组合（kelt+fixed，+$2,599）形式上超过 732.7，
但两者不同引擎不同口径，不构成可比声明。

## 诚实条款

- 两个 bug 均在"结果好得难以置信"的反直觉检验（sanity 复现链、物理吞吐上限、月月全正的统计不可能性）下暴露；
  修复后全部实验重跑，本文件所有数字来自修复后引擎。
- kelt+fixed 的参数（TP2.5/SL0.4/90min、EMA20±2ATR14）是在同一数据上多组合比较后报告的最优，
  存在选择偏差；逐年全正性未达到（2024 微负）。
- 随机+fixed 的 +$6.1K 是 TP 远 SL 近的截断分布性质（5 seeds 稳定），但 2024 年 -$2.6K、
  抗滑点为零，不具可部署性，仅作分布参照。
