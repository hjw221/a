## 1. R1 自我进化: 35 臂网格 → 冠军配置

**根因诊断 (为什么 v1 的 D=505 维不行)**: λ=0.999 的 RLS 有效记忆 ≈1000 bar,
D=505 时每维仅 ~2 个有效样本 — 严重欠定。**缩小储层 = 改善 RLS 条件数**,
这是本轮最大的单一发现。

冠军进化链 (IC_var@h4):
```
v1 基线 (nres500, raw, 4feat, λ0.999)     0.3426   [bitwise回归复现 ✓]
+ log1p 方差目标                           0.3361   (训练空间IC 0.3795, 规范口径略降)
+ 8维输入 (session sin/cos + 慢ATR比 + 1h动量)  0.3679  [Stage B 因子结论复现]
+ log + 8维 (a13)                          0.3704
+ nres300 → 200 → 150 → 100 → 75 → 50     0.407 → 0.421 → 0.433 → 0.449 → 0.452 → 0.467
+ λ 0.999 → 0.9995 → 0.9998 → 0.9999      0.481 → 0.489 → 0.491
= 冠军: nres50 + λ0.9999 + log目标 + 8维    **0.4907**
```

被证伪的改进臂 (诚实记录): 多尺度漏积分储层 (4维下有效, 8维下有害),

### 部署含义
D=55 的 RLS: P 矩阵 55²×8B = 24KB; 全引擎 <100KB 常驻。
**0.10ms/bar 意味着可以在 M1 粒度运行 (v1 只敢 M15)**, 或在树莓派级硬件跑 M15。

## 2. v3bal_ens 修复 + 联动实验

### 2.1 v3bal_ens 时域 bug 修复 (基建侧产出)
v2_ens 管线 6 处 `astype("int64")//10**9//60` 在服务器 pandas 3.0.6 的
datetime64[us] 下产生千秒域 → 入场最多迟到 ~17 分钟 + 平台期碰撞吞信号。
**9/30 的 409 笔/−$40.7 是 bug 产物** (答案: 不是模型退化, 是时间戳坏死;
且当时 wf 被旧 checkpoint 短路回放了 9/30 结果 — 两层坑同时挖穿才见到真相)。

修复 (datetime64[s] 中转, pandas 2/3 双安全) + 全状态清空重跑:
```
修复版 v3bal_ens: 1657笔 胜率0.302 PLR 2.62 PnL +$740.0 Sharpe 1.13
历史基准:        1611笔 胜率0.316 PLR 2.57 PnL +$1113.5 Sharpe 1.74
bug版(9/30):     409笔 胜率0.291 PLR 2.36 PnL −$40.7
```
残差 ($740 vs $1113) = 库版本/线程非确定性, 结构已还原 (交易数/胜率/PLR 吻合)。

### 2.2 联动实验 (R1 冠军预测流 × 1657 笔交易流)
| 机制 | 结果 | 判读 |
|---|---|---|
| L1 择时闸门 R≥1.2 才执行 | 265笔, $0.68/笔, PLR 1.22, Sharpe 4.63 | 每笔质量+51%但饿死总量; **shuffle对照 $0.33/笔 → 真实择时信息存在但小幅** |
| L1 低能执行 R≤0.7 | 806笔, $0.62/笔, Sharpe 5.18 | 中能带(0.7-1.2)是最差区间 — U型结构 |
| L2 呼吸阀 size=min(1,med/R) | $652 (avg size 0.843), PLR 不变 | ≈线性缩放, 无alpha增益; 但省16%保证金占用 (杠杆约束账户有价值) |

**联动诚实结论**: R1 对 v3bal_ens 的入场时刻有真实 (shuffle 可证) 但
小幅的每笔信息提升; 它不是这个 M1 策略的 PnL 放大器。
能量预测的 1h-4h 视界与 M1 障碍交易 (中位持仓 34 分钟) 存在视界错配 —
与 v19 教训 (5日持仓 vs 1h 视界) 同型但反向。

## 3. 四用途重新评估 (R1 进步后)

### UC1 网格防毒流装甲 — 尾部有效, 均值无效
被动买挂单 (close−0.25×ATR, 成交持有4bar) 按 R 十分位分层:
- 均值逆向偏移: 各分位 ~$0.0±0.2 无梯度 (均值层面装甲不存在)
- **p5 尾部: d1 −$3.5 → d9 −$14.0 (4×恶化)** — 预测高能期的被动单被碾尾
- 部署判读: 装甲保护的是**尾部**不是均值; d8-d10 区间撤单/拉宽3×的规则
  消灭的是爆仓尾, 代价是错过部分正fill — 与网格策略的死因结构吻合

### UC2 动态 VaR 呼吸器 — 强证据, 校准近乎完美
- 十分位实现方差: 0.345→2.525 (**7.32× 价差**)
- 线性斜率 **1.043** (R+1 → 实现方差+1.04×) — 预测即校准
- Exposure=min(1, Base/σ̂²) 公式的输入端是可靠的;
  实盘部署成本为零 (R1 已在 M15 流式运行)

### UC3 黑天鹅断路器 — 快速反应器 + 温和前瞻
- 极端行情事件 (|ret|>p99.5, n=525, 含 2022-02-24 俄乌入侵×5):
  d2 轨迹在事件当根跳至 16.7 (基线 ~8), 事件前4根 d2≥25 比例 7% vs 基线 0.63%
  (**前瞻 lift 11.5×**, 覆盖率 7% — 真但稀)
- **d2>25 → 未来 1h 实现方差 = 5.9× 中位** (114 事件, 冠军 metrics 口径)
- 部署判读: 断路器的主价值是**冲击后冻结** (跳过冲击后的湍流小时),
  不是预测冲击本身; 前瞻 7% 是彩票不是雷达

### UC4 跨资产编码器 — 强证据, 唯一提升 IC 的用途
DXY/XAG 数据 (filester.me, 2022.01-2026.06, M1, 与 XAUUSD 同窗):
- R1 冠军配置直接迁移: DXY 自身 IC 0.4915, XAG 0.5185 (引擎跨资产泛化 ✓)
- **传输结构**: XAG 能量滞后 120min → XAU 未来 4h 方差 IC 0.5506
  (超过 XAU 自身当前状态对 4h 的 0.4478) — 白银能量领先黄金
- **嵌合引擎**: XAU 8维 + [R_dxy, R_xag 滞后30min] → **IC_var 0.5363**
  (+d2 特征: 0.5384); h8: 0.5509
- shuffle 对照: 0.4738 (< 单资产基线, 乱序特征纯添噪) — 增益真实
- 部署判读: use case 4 是四个用途中唯一同时 (a) 提升 IC (b) 通过 shuffle
  (c) 有物理传导机制 (白银↔黄金微观结构联动, 美元指数↔金价) 的方案

## 6. 事后修正 (2026-10-03 晚 · 天气站移植时发现)

### 6.1 嵌合引擎 IC 0.5363 = asof 未来信息伪影 (撤回该结论)

天气预警站把冠军引擎移植到 TypeScript 时采用**严格实时因果** (嵌合输入只用决策时刻已收盘的
DXY/XAG bar), 嵌合 IC 掉回 **0.4915 ≈ 单资产基线**。lag 消融定位根因:

| asof lag | 语义 | 嵌合 IC |
|---|---|---|
| 15min | 严格因果 (DXY bar 与 XAU bar 同槽收盘) | **0.4915** |
| 30min | R2 原口径 — 允许 DXY bar [T+15,T+30) | 0.5363 |
| 45min | 允许 [T+30,T+45) | 0.5715 |
| 60min | 允许 [T+45,T+60) — 深入标签窗口 | **0.5868** |
| 120min | 越出标签窗口 (T+105,T+120) | 0.5390 |

标签窗口 = (T+15, T+75]; lag≥30 的 asof 允许输入 bar 与标签窗口前段重叠 — IC 随重叠深度
单调上升、越出标签窗后回落 = 泄漏曲线。**shuffle 对照无法区分泄漏与真实领先** (两者都依赖
时间对齐), lag 消融才是决定性对照。修正后的跨资产结论:

- 嵌合 (作为特征输入): 严格因果下增益归零 — **撤回 "IC 0.49→0.54 的唯一提升通道" 结论**
- 白银→黄金传输 (R_xag(t) vs XAU 未来4h方差, 无窗口重叠): **仍然真实** (IC 0.55) —
  正确用法是独立预警信号, 不是嵌合特征
- 附带真实增益: XAU 专用 h16 训练引擎把 4h 预报 IC 提到 **0.5188** (天气站已部署)
